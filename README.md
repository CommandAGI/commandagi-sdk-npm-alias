# commandagi

An alias for **[`@commandagi/sdk`](https://www.npmjs.com/package/@commandagi/sdk)** — the Node/TypeScript
client for [CommandAGI](https://commandagi.com), and the `cagi` CLI.

```bash
npm install commandagi        # this package — re-exports @commandagi/sdk
npm install @commandagi/sdk   # the same thing, by its canonical name
```

Everything `@commandagi/sdk` exports is re-exported here unchanged; there is no separate
implementation and no separate API. If you are starting fresh, prefer `@commandagi/sdk`.

Python: `pip install commandagi`. Go: `go get github.com/commandAGI/commandagi-go`.
